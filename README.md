# 모아잇 (moait)

## 🛠 기술스택

| 구분         | 기술                                      |
| ------------ | ----------------------------------------- |
| **Frontend** | Vue 3, Composition API, Pinia, Vue Router |
| **Styling**  | Tailwind CSS, shadcn-vue                  |
| **통신**     | axios                                     |
| **빌드**     | Vite                                      |

## 🚀 시작하기

```bash
npm install
npm run dev
```

| 스크립트          | 설명                    |
| ----------------- | ----------------------- |
| `npm run dev`     | 개발 서버 실행          |
| `npm run build`   | 프로덕션 빌드           |
| `npm run preview` | 빌드 결과 미리보기      |
| `npm run lint`    | ESLint 검사 + 자동 수정 |
| `npm run format`  | Prettier 포맷           |
